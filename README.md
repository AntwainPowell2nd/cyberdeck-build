# Cyberdeck Build

A custom portable computer built around a Raspberry Pi 4B running Kali Linux 
for network security research and RetroPie for retro gaming.

## Goal
Build a fully functional handheld pentesting and gaming deck from scratch 
as a hands-on introduction to embedded systems, Linux, and cybersecurity.

## Hardware (planned)
- Raspberry Pi 4B — 8GB RAM
- Waveshare 7" IPS Touchscreen (1024x600)
- Waveshare UPS HAT (C) + 2x Samsung 30Q 18650 batteries
- Alfa AWUS036ACS USB WiFi adapter (monitor mode for pentesting)
- Arteck HB030B Bluetooth keyboard

## Software
- Kali Linux ARM (pentesting)
- RetroPie (retro gaming)
